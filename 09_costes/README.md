# 09 · Costes y facturación

- **Vídeo:** [Curso Completo de AWS (Amazon Web Services) | Desde CERO en ESPAÑOL!](https://www.youtube.com/watch?v=NxhLT4ehhOw&t=12957s), de [Joan Amengual](https://www.youtube.com/channel/UCQB8dgeFkuKXVtzweRM_Zfw)
- **Tramo:** 3:35:57 – 3:50:13
- **Apunte:** [apuntes/09-costes-facturacion.md](../apuntes/09-costes-facturacion.md)

En el vídeo todo se hace desde la consola. El script es el equivalente con la AWS CLI y **no aparece en el vídeo**.

| Archivo | Qué es |
|---------|--------|
| `cli-costes.sh` | Gasto por servicio y por etiqueta, previsión del mes, etiquetas de asignación de costes |
| `costes-ejemplo.csv` | Extracto inventado de un informe de costes, para los ejercicios |
| `ejercicios/` | Agrupar coste por servicio, ranking de gasto, previsión y etiquetas de usuario (arregla el código) |

> `cli-costes.sh` solo consulta y etiqueta: no crea nada que cueste dinero. Los datos del CSV son inventados,
> no salen de ninguna cuenta real.
